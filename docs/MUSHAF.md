# Quran Mushaf and Werd

Open **Wellbeing → Quran Mushaf** to read all 114 surahs offline. Use the selectors to jump to a surah, juz, or numbered Madinah Mushaf page. **Bookmark page** saves the page to resume from. The reader adapts the text to the available width and uses the printed Mushaf page divisions.

Select **New Mushaf Werd** and choose a title, starting page, pages per day, and reminder time. **Open today’s reading** takes you to the assigned range. **Mark today complete** advances the plan. A new cycle starts at page 1 when you finish page 604. An unread range stays assigned until you mark it complete.

Sabri delivers one notification per active Werd per local day. Keep Sabri running in the tray and enable notifications in Settings. If Sabri opens after the reminder time, it can still deliver that day’s reminder. The notification uses the time zone set in Sabri.

The Arabic text and Madinah page divisions come from the Tanzil Project. The download’s copyright and license notice accompanies the bundled data. Rebuild the dataset with `node scripts/import-mushaf.mjs`.
